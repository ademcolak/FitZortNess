# Licensed exercise media research

Date: 2026-07-16

## Outcome

Wikimedia Commons has several exercise GIFs whose file pages explicitly identify the copyright holder, source and reuse license. Five candidates are both legally reusable and close enough to an existing FitZortNess exercise ID to be considered for the first ingestion batch:

- `0662` — push-up
- `1160` — burpee
- `0652` — pull-up
- `0748` — smith bench press
- `0032` — barbell deadlift

Three further files are legally promising but should not be enabled yet: the squat has no exact bodyweight-squat record in the current dataset, the curl needs a visual/equipment match before mapping, and the CDC overhead-press file has a public-domain determination tied to U.S. federal-government law.

This is a rights review, not a biomechanics or coaching-quality review. Wikimedia Commons verifies licensing information, not whether a movement demonstration is safe or technically ideal. Before `enabled: true`, each animation needs a manual subject and exercise-variation match review. A qualified movement-form review is additionally required before any animation is described as authoritative coaching material; enabled media remains labelled as a general visual reference.

## License rules that apply

[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) both allow copying, redistribution and adaptations for commercial purposes. They require appropriate attribution, a license link and compliance with ShareAlike for adaptations. Version 4.0 also requires indicating modifications; the 3.0 deed requires this when a derivative is made.

The Creative Commons deeds also warn that copyright permission does not automatically clear other rights such as privacy, publicity or moral rights. This matters most for the pull-up GIF because it depicts an identifiable person rather than a drawing.

## Proposed ingestion policy

1. Start with the exact-match candidates only; never infer an equipment variant from a generic exercise label.
2. Manually confirm the depicted exercise and equipment variation before enabling media. Require a qualified movement-form review before presenting it as authoritative coaching material; otherwise retain the general-visual-reference disclaimer.
3. Download from the recorded `upload.wikimedia.org` URL, compute SHA-256 locally, and store that digest in `media/exercise-media.json`.
4. Preserve the source filename where practical and show author, source page, license name, license URL and modification status in attribution.
5. If a GIF is edited, cropped, recolored or transcoded, record the change and apply ShareAlike to the adapted media file. Do not represent the entire application as CC BY-SA merely because it contains an unmodified CC BY-SA asset; keep the asset and its attribution/license boundary explicit.
6. Re-check the Commons file page immediately before ingestion and keep a dated copy of the metadata used for the decision. A direct media URL alone is not evidence of permission.

## Integration decision

After local file and subject/variation review, the first enabled set is `0662` (push-up), `1160` (burpee), and `0032` (barbell deadlift), displayed with an in-chat general-visual-reference disclaimer. The pull-up file remains excluded because the source does not establish a separate commercial model release for the identifiable person. `SmithMachineBenchPress.gif` was also excluded after visual review because it is a photo of a real person, not a drawing, and the demonstrated setup should not be presented as authoritative form guidance without a qualified review.

## Exclusions

- No GIF found in this pass was confidently suitable for a barbell/dumbbell row while also matching the current GIF-only transport path. Commons has reusable row videos and still images, but they are outside this task's current media type.
- Generic image-search, Tenor, Giphy, Pinterest and the existing exercise-dataset GIF URLs were not treated as license evidence.
- Files with unclear authorship, “free to use” prose without a standard redistribution license, or mismatched exercise variants were excluded.
